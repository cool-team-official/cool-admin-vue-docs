# 国际化

国际化插件，支持多语言切换。

## 配置

在 `config/index.ts` 中配置：

```js
{
  i18n: {
    locale: "zh-cn",
    languages: [
      {
        label: "中文",
        value: "zh-cn",
      },
      {
        label: "繁体中文",
        value: "zh-tw",
      },
      {
        label: "English",
        value: "en",
      },
    ];
  }
}
```

## 使用

需要翻译的内容需要在 `$t()` `t()` 中使用，例如：

```js
// html
$t("你好");

// js
const { t } = useI18n();
t("你好");
```

内容使用 `中文`，ai 会全文检索并自动翻译成其他语言。

## 翻译

安装翻译工具

```cmd
pnpm i @cool-vue/ai -g
```

运行命令

```cmd
创建翻译文件
cool-i18n create

清除翻译文件
cool-i18n clear

添加模块/插件翻译文件，例如：
cool-i18n add plugins/crud
cool-i18n add module/user
```

执行完成后，会在对应的模块、插件目录下生成 `locale` 目录。
