# 开发工具

只在开发环境生效，方便开发调试。

## 接口管理

可以查看所有的接口，并进行筛选和配置，方便管理和调试。

<img src="/images/dev-tools-eps.jpg" />

## 代理管理

展示了所有的代理配置，可以通过可视化界面轻松切换代理，简化开发过程。

<img src="/images/dev-tools-proxy.jpg" />

## 字典管理

查看和管理所有的字典数据，确保数据的一致性和准确性。

<img src="/images/dev-tools-dict.jpg" />

## 账号切换

允许查看所有的账号，并通过可视化界面进行账号切换，方便测试和调试不同用户权限。

<img src="/images/dev-tools-account.jpg" />
